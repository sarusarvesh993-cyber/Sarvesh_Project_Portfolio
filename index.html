How I work

Four habits behind the projects.

Practical constraints make projects more credible than unmeasured demos.

01

Start with the decision

Define what someone should be able to decide after seeing the result.

02

Separate evidence from assumptions

Label synthetic data, simulations and unmeasured claims rather than hiding them.

03

Test important logic

Use deterministic checks for calculations, transformations and API boundaries.

04

Document the limits

State what a result cannot prove and what a production version would still need.
