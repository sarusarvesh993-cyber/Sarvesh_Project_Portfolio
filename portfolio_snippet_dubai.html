Dubai Property Decision Engine

A daily-refreshed decision product on official Dubai Land Department open data (163,000 registered transactions and 607,000 Ejari rent contracts). It answers four questions people actually face: is this asking price fair, can my landlord raise the rent, which communities are heating up or cooling, and what looks mispriced. A question box answers in plain language from the published benchmarks only.

My role
Problem framing, data pipeline, SQL models, back-test, web app, documentation and operations
Tools
Python, pandas, DuckDB SQL, GitHub Actions, Next.js and TypeScript, Vercel, free-tier LLM router
Evidence
Published back-test: median error 6.2% against 20.5% for a citywide median on 8,350 sales; 17 data-quality checks and a 29-question copilot evaluation run on every refresh
Data
Official DLD gateway, registered sales and Ejari contracts, refreshed every morning
What made this difficultRegistrations are not all market sales. Land plots with a residential label, half-share transfers and whole buildings registered unit by unit at one price were distorting medians; each became a flag, an exclusion rule and a quality check. The AI layer never computes: retrieval first, a rules answer, then a model rewrites the prose and a guard rejects any new number.
